# 決定事項

## 決定済み

| 領域 | 決定 |
| --- | --- |
| 提供形態 | 一般公開を目指すWebサービス。PC中心で将来アプリ対応 |
| 対象 | 日本国内、13歳以上、日本語UI |
| 料金 | 無料・広告なし |
| 認証 | Googleアカウントのみ |
| 内部ID | ULID |
| 公開ID | 重複しないハンドル |
| 書籍モデル | 作品は共通、単行本・文庫・電子版などの版を分離 |
| 読みたい本 | 版を決めず作品単位で登録可能 |
| 所有 | 読書状態と分離し、入手・手放し履歴を保持 |
| 読書状態 | 読みたい、未読、読書中、読了、中断 |
| 進捗 | ページ数・割合・時間を記録しない |
| 再読 | 読書ごとに別の履歴を保存 |
| 同時読書 | 1作品につき進行中の記録は1つ |
| 評価 | 読書記録ごとに星1〜5の整数 |
| 感想 | 読書記録ごとのプレーンテキスト。ネタバレ設定あり |
| メモ | ユーザーと作品ごとに1つ。常に非公開 |
| タグ | ユーザー固有の自由タグ。公開本ではタグも公開 |
| 公開範囲 | プロフィール全体と本ごとに公開・非公開を選択 |
| 公開履歴 | 公開本では過去の読書記録をすべて表示 |
| 所有の公開 | 現在状態のみ。所有履歴は非公開 |
| 交流 | 初期版にフォロー、いいね、コメントを入れない |
| 検索 | 作品、著者、公開ユーザー。感想本文は対象外 |
| 手動書籍 | 共通カタログへ即時追加 |
| 書誌編集 | 修正申請を運営が反映 |
| 表紙 | 外部書籍情報サービスから取得。アップロードなし |
| プロフィール画像 | Google画像または共通初期画像 |
| 統計 | 基本集計、年別・月別読了、ジャンル傾向 |
| 未ログイン | 作品、公開プロフィール、本棚、感想を閲覧可能 |
| 検索エンジン | ユーザーが掲載可否を選択。初期値は掲載しない |
| 通報 | プロフィール、感想、手動書籍を対象とする |
| 投稿審査 | 即時公開し、通報に基づく事後対応 |
| データ出力 | 蔵書CSVと完全データJSON |
| 退会 | 即時非表示、7日間取消可能、その後完全削除 |
| メール | 規約、セキュリティ、出力、退会など重要通知のみ |
| テスト | 運営だけが固有招待URLを発行するクローズドテスト |
| Web技術 | TanStack Start + React + TypeScript |
| 実行環境 | Cloudflare Workers |
| DB | 外部マネージドPostgreSQL |
| 仕様サイト | VitePress + GitHub Pages |

## 未決事項

実装開始前に、根拠と比較結果を残して決定します。

- サービス名称とドメイン
- ハンドルの正確な文字種、長さ、予約語
- 表示名、自己紹介、感想、メモ、タグの文字数上限
- 書籍情報・表紙の取得元と利用条件
- 外部PostgreSQLの提供元とCloudflareからの接続方式
- ORM、マイグレーションツール、認証ライブラリ
- メール配信サービス
- 監査情報の保持期間
- 退会処理における法的保持データ
- 性能・可用性の具体的な目標値
- クローズドテストの人数と期間
- テストデータを正式版へ引き継ぐ条件

## 変更ルール

仕様を変更するときは、次を同じPull Requestで更新します。

1. 影響する仕様ページ
2. このページの決定事項または未決事項
3. データモデルやロードマップへの影響
4. すでに実装済みの場合は移行方針
