## このドキュメントについて

このサイトは、Libraryのプロダクト仕様に関する唯一の基準点です。仕様変更は、該当ページと[決定事項](/decisions)を同じ変更内で更新します。

### 現在のフェーズ

**仕様策定 — クローズドテスト版の開発前**

初期リリースは日本国内の13歳以上を対象とした、無料・広告なしのクローズドテストです。招待URLは運営管理者だけが発行します。
