# プロダクト仕様

## 1. サービス概要

Libraryは、蔵書、所有履歴、読書状態、再読履歴、評価、感想、個人メモを一か所で管理できるWebサービスです。利用者は自分の記録を非公開で管理でき、希望する本だけを公開プロフィールで共有できます。

### 1.1 目的

- 読みたい本と所有している本を混同せず管理できる
- 過去の読書を上書きせず、再読による変化を残せる
- 公開したい記録と私的な記録を明確に分けられる
- PCを中心に快適に利用でき、将来のモバイルアプリへ発展できる

### 1.2 対象

- 日本国内の13歳以上
- 初期UI、規約、サポートは日本語のみ
- 日本語以外のタイトルと著者名も登録可能
- 初期版は無料・広告なし

### 1.3 対象外

初期版では以下を提供しません。

- フォロー、いいね、コメント、タイムライン
- 読書ページ数、進捗率、読書時間、連続読書日数
- ユーザーによる表紙・プロフィール画像のアップロード
- 読書リマインダー、宣伝メール、ニュースレター
- データのインポート
- 多言語UI

## 2. 認証とアカウント

### 2.1 Googleログイン

- 認証方法はGoogleアカウントのみとする
- Googleの不変なアカウント識別子をログインIdentityへ紐づける
- メールアドレスをアカウントの主キーにしない
- メールアドレスは公開しない
- 将来ほかの認証プロバイダーを追加できるよう、UserとIdentityを分離する

### 2.2 初回設定

初回ログイン後、利用開始前に次を設定します。

1. 13歳以上であることと規約への同意
2. 重複しない公開用ハンドル
3. 重複可能な表示名
4. Google画像または共通初期画像
5. プロフィール全体の公開設定
6. 新しく登録する本のデフォルト公開設定
7. 検索エンジンへの掲載設定

Googleの名前と画像は候補にのみ使用し、本人の確定前には公開しません。

### 2.3 識別子

| 項目 | 用途 | ルール |
| --- | --- | --- |
| 内部ID | DB上の関連付け | ULID、変更不可、原則非公開 |
| ハンドル | プロフィールURL | 重複不可、英小文字・数字・アンダースコアを想定 |
| 表示名 | 画面表示 | 重複可、変更可能 |

ハンドルは30日に1回変更できます。旧URLは新URLへ転送し、旧ハンドルはなりすまし防止のため再割り当てしません。

### 2.4 セッション

- 最終利用から30日でGoogleによる再ログインを求める
- 設定画面から、すべての端末のセッションを無効化できる
- 退会または利用停止時は全セッションを即時無効化する
- 端末ごとのセッション管理は初期版の対象外とする

## 3. 書籍カタログ

### 3.1 作品と版

書籍は「作品」と「版」を分けて管理します。

- 作品ページ、感想、平均評価は作品に集約する
- 単行本、文庫、電子版などは版として区別する
- 所有履歴と読書記録は実際の版へ紐づける
- 「読みたい」段階では版を選ばず、作品だけを登録できる
- 入手または読書開始時に版を選択する
- 再読時に前回とは異なる版を選択できる

### 3.2 書誌情報

| 作品 | 版 |
| --- | --- |
| タイトル | ISBN |
| 複数の著者 | 版の種類 |
| あらすじ | 表紙 |
|  | 出版社 |
|  | 発売日 |

翻訳者、シリーズ、言語、原題を将来追加できる構造にします。

### 3.3 検索と手動登録

- タイトル、著者、ISBNで検索できる
- 見つからない本は手動登録できる
- 手動登録した作品・版は共通カタログへ即時追加する
- ISBNは一意とし、重複登録を拒否する
- 登録前にタイトルと著者が類似する候補を表示する
- 運営は重複した作品・版を統合できる

共有書誌情報は運営だけが直接編集できます。ユーザーは修正を申請します。ただし、登録直後かつほかの利用者が使っていない手動登録データは、登録者本人が修正できます。

### 3.4 表紙

- 書籍情報サービスから取得した画像だけを使用する
- 取得できない場合は共通のプレースホルダーを表示する
- ユーザーによる画像アップロードは提供しない
- 採用するサービスごとに、画像の利用条件とキャッシュ可否を確認する

## 4. 個人の本棚

### 4.1 所有状態

読書状態とは別に、次の現在状態を管理します。

- 未所有
- 所有
- 借り物
- 手放した

入手と手放しは履歴として保持し、入手日と手放した日を記録できます。同じ版を買い直した場合も別の所有履歴として扱います。「借り物」では返却期限、相手、図書館名を管理しません。

公開ページには現在の所有状態だけを表示し、入手日と手放した日を含む履歴は本人だけが閲覧できます。

### 4.2 読書状態

状態は次の5種類です。

| 状態 | 意味 |
| --- | --- |
| 読みたい | 将来読みたい。版と所有の有無は問わない |
| 未読 | 本棚にあるが、現在は読んでいない |
| 読書中 | 進行中の読書記録がある |
| 読了 | 最新の読書記録を読み終えている |
| 中断 | 最新の読書記録を途中で終了している |

ページ数、進捗率、読書時間は記録しません。

### 4.3 読書記録と再読

- 読書を開始するたびに独立した記録を作成する
- 過去の記録を上書きしない
- 1作品につき、同時に進行できる読書記録は1つとする
- 記録ごとに版、開始日、終了日、結果、評価、感想を持つ
- 読書中から状態を戻す際は「中断として保存」または「誤操作として削除」を選べる

開始日・読了日は、年月日、年月、年のみ、または不明を表現できます。通常の操作では現在日を自動入力し、後から修正できます。

期間別統計は、その期間を判定できる精度の日付だけを使用します。日付不明の読了記録は総読了数には含めます。

### 4.4 評価

- 星1〜5の整数
- 未評価を許可し、星0とは扱わない
- 読書記録ごとに評価できる
- 作品の平均評価は1件から表示し、件数を併記する
- 平均評価には、公開されている各ユーザーの最新評価だけを1票として使用する

### 4.5 感想

- 読書記録ごとにプレーンテキストで入力する
- 改行を反映し、画像添付や文字装飾は提供しない
- 感想全体へ「ネタバレあり」を設定できる
- ネタバレ感想は初期状態で本文を伏せ、閲覧者の操作後に表示する
- 検索候補や一覧にネタバレ本文を露出させない
- 投稿者は編集・削除できる
- 編集後は「編集済み」と表示し、変更履歴は運営だけが確認できる

### 4.6 非公開メモ

- ユーザーと作品の組み合わせごとに1つ持つ
- 版や読書記録が変わっても同じメモを維持する
- 公開設定にかかわらず、常に本人だけが閲覧できる

### 4.7 自由タグ

- ユーザーは本へ複数の自由タグを設定できる
- タグはユーザーごとに管理する
- 大文字・小文字などを正規化し、同一ユーザー内の重複を防ぐ
- 名称変更と削除は関連する本へ一括反映する
- 公開した本のタグは公開し、非公開本にしかないタグは公開一覧へ出さない

### 4.8 本棚からの削除

利用者は次を選択できます。

- **本棚から非表示**：所有・読書記録などを保持したまま通常の本棚から隠す
- **完全削除**：所有履歴、読書記録、評価、感想、メモ、タグの関連を削除する

完全削除前には対象データを明示して確認します。

## 5. 公開とプライバシー

### 5.1 公開単位

- 初回設定でプロフィール全体の公開・非公開を必ず選ばせ、初期選択は非公開とする
- プロフィールを非公開にすると、公開設定済みの本も含めてすべて外部から隠す
- 再公開時に本ごとの設定を復元できるよう、設定値自体は変更しない
- 本ごとに「公開」「非公開」を設定する
- 新規登録時はユーザーが選んだデフォルト値を使用する
- 非公開本は存在、統計、タグから推測できないようにする

### 5.2 公開される情報

公開本では次を表示します。

- 現在の所有状態
- 現在の読書状態
- 再読を含むすべての読書記録
- 記録ごとの開始日、終了日、評価、感想
- 自由タグ

所有履歴と個人メモは公開しません。

### 5.3 公開プロフィール

- URLは `/users/{handle}` とする
- 表示名、アイコン、自己紹介、公開本棚を表示する
- 公開データだけで集計した読書統計を表示する
- 活動タイムラインは表示しない
- 検索エンジンへの掲載可否をユーザーが選べる
- 掲載設定の初期値は「掲載しない」とする

### 5.4 未ログイン利用

ログインしていない利用者も次を閲覧できます。

- 作品と版の情報
- 公開プロフィール
- 公開本棚
- 公開感想

登録、評価、投稿、通報などの操作にはGoogleログインが必要です。

## 6. 検索と画面

### 6.1 検索対象

- 作品名
- 著者名
- 公開プロフィールのハンドルと表示名

感想本文は初期版の検索対象にしません。非公開プロフィールと非公開本は結果に表示しません。

### 6.2 ログイン前トップ

- サービスの説明
- 作品・著者検索
- Googleログインへの導線
- 人気作品、ランキング、新着感想は初期版では表示しない

### 6.3 ログイン後ホーム

- 読書中の本
- 読みたい本
- 未読本
- 最近読了した本
- 自分の本棚検索
- 状態と自由タグによる絞り込み

作品探索とユーザー検索は別画面とします。

### 6.4 統計

本人向け統計は公開・非公開を含む全記録、公開プロフィールは公開記録だけを使用します。

- 現在の蔵書数
- 読書中の作品数
- 読了数
- 平均評価
- 年別・月別の読了数
- ジャンル傾向

## 7. 通報と運営

### 7.1 通報

ログイン済みユーザーは次を通報できます。

- 公開プロフィール
- 公開感想
- 手動登録された書籍情報

通報理由と任意の補足を受け付け、通報者の情報は対象ユーザーへ公開しません。同じ対象への重複通報と、通報機能自体の悪用を検知します。

### 7.2 投稿の公開

- 感想は投稿後すぐに公開する
- 短時間の大量投稿にはレート制限を適用する
- 運営は確認中の投稿を一時的に非表示にできる
- 違反を繰り返すユーザーは投稿制限または利用停止にできる

### 7.3 管理画面

- 招待URLの発行・失効・利用状況確認
- 通報の確認・対応・却下
- 投稿の非表示
- ユーザーの投稿制限・利用停止
- 書籍情報の修正と重複統合
- 書籍修正申請の確認
- 必要な監査履歴の閲覧

## 8. 招待とリリース

- 最初は少人数のクローズドテストとする
- 運営管理者だけが一人ずつ固有の招待URLを発行する
- 招待には有効期限と使用回数を設定できる
- 使用済み、期限切れ、失効済みの招待は利用できない
- 招待元を運営側で確認できる
- 公開ベータ移行後は招待確認を無効化する

## 9. メール

次の重要な通知だけを送ります。

- 規約とプライバシーポリシーの重要な変更
- 不審なログイン、利用停止などのセキュリティ情報
- データエクスポート完了
- 退会処理と完全削除の完了

## 10. データ出力と退会

### 10.1 エクスポート

- 蔵書一覧をCSVで取得できる
- 読書記録、評価、感想、メモを含む完全データをJSONで取得できる
- 非公開情報を含むため、生成前にログインを再確認する
- 初期版ではインポートを提供しない

### 10.2 退会

1. 退会操作直後にプロフィールと公開データを非表示にする
2. 全セッションを無効化する
3. 7日間は退会を取り消せる
4. 7日後に蔵書、所有履歴、読書記録、評価、感想、メモ、Identityを完全削除する
5. 平均評価などの集計を再計算する
6. 完全削除後は復元できない

不正対策や法的義務のため最小限の監査情報を一時保持する場合は、目的と期間を規約へ明記し、ユーザーデータから分離します。
